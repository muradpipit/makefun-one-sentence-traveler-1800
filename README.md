A one-sentence explanation of the modern internet for a traveler from 1800: a road of light where every library, post office, and market in the world stands side by side, and any letter you write arrives before the ink dries. One sentence, 157 characters, built only from words a person from 1800 could picture.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
